# Memrize

Сетка карточек с эмодзи. Учебный вариант игры Memorize.

## Что умеет приложение

На экране карточки. Кнопки с минусом и плюсом меняют их число. Кот и собака переключают набор: кошачьи эмодзи или собачьи.

## Курс

Упражнение в духе Stanford CS193p, задание Memorize.

## Стек

SwiftUI.

## Запуск

```bash
git clone https://github.com/dpogonia/Memrize-CS193p.git
cd Memrize-CS193p
open Memrize.xcodeproj
```

Запустите схему **Memrize** на симуляторе iPhone.
