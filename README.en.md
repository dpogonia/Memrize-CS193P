# Memrize

A grid of emoji cards. A study take on the Memorize game.

## What it does

The screen shows cards. Minus and plus change how many are visible. A cat and a dog switch the set between cat emoji and dog emoji.

## Course

An exercise in the style of Stanford CS193p, the Memorize assignment.

## Stack

SwiftUI.

## Run

```bash
git clone https://github.com/dpogonia/Memrize-CS193p.git
cd Memrize-CS193p
open Memrize.xcodeproj
```

Run the **Memrize** scheme on an iPhone simulator.
